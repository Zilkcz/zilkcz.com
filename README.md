# zilkcz.com

Personal portfolio site built with Next.js, TypeScript and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Edit the copy in `src/app/page.tsx`, the shelves in `src/data/likes.ts` and the footer links in `src/data/socials.ts`.

## Deploy

1. Import this repo into Vercel (or Netlify / Cloudflare Pages).
2. Add `zilkcz.com` as a custom domain and set the DNS records the host asks for.
